## 주요 기능

| 메뉴 | 기능 |
| :--- | :--- |
| **CAS** | 카테고리 변경 · CAS 순서 정렬 · 머리 모양 자동 색상 분류 |
| **BUILD** | 건축·구매 카테고리 변경 · 여러 카테고리 지정 |
| **POSE** | 설명 태그 변경 · 개별 포즈 이름·설명·썸네일 편집 · 순서 변경 |
| **MOD** | 모드 파일 분류 · 활성화 및 비활성화 |
| **SLIDER** | 조작점·시점·조작축별 슬라이더 조회 · 겹침 확인 |
| **진단실** | 점검 대상 조회 · 중복 파일 검사 · 50:50 검사 |
| **관리실** | 파일·폴더 덮어쓰기 · 캐시 및 오류 기록 정리 |
| **한글화** | 한글화 파일 적용 · 수동 번역 · 한국어 번역 파일 내보내기 |
| **즐겨찾기** | 즐겨찾는 파일을 폴더별로 정리 |
| **설정** | 프로필 · 화면 테마 · 화면 크기 설정 |

## 다운로드 및 업데이트

사용 중인 운영체제에 맞는 **Windows 또는 macOS** 설치 파일을 내려받아 설치해 주세요.
설치된 앱에서는 새 버전의 자동 업데이트를 지원합니다.

## 파일 처리 안내

모드룸은 AI나 외부 분석 API에 의존하지 않고 파일을 직접 분석하고 편집하도록 설계되었습니다.  
모든 파일 분석과 편집은 사용자의 컴퓨터에서 처리되며, 모드 파일은 외부로 전송되지 않습니다.

## 이용약관

- 본 프로그램의 모든 저작권은 **XOOX**에게 있으며, EA와 무관한 별도의 프로그램입니다.
- 프로그램에 포함된 제3자 소프트웨어와 자료에는 각 권리자 라이선스가 적용됩니다.
- 제작자의 사전 허락 없는 프로그램의 **복제·수정·재배포·판매를 엄격히 금지**합니다.
- 프로그램을 공유할 때는 반드시 공식 배포 게시물의 **링크**를 전달해 주세요.
- 개인의 보안과 안전을 위해 반드시 **공식 배포 링크를 확인한 뒤 다운로드해 주세요.**
- 공식 배포처 외의 경로에서 내려받은 프로그램의 변조나 악성코드로 인해 발생한 문제에 대해서 책임지지 않습니다.
